# 📊 InsightTube – YouTube Analytics Platform

InsightTube is a powerful **YouTube Analytics Web Application** built using **Streamlit**.  
It leverages the **YouTube Data API v3** to fetch, analyze, and visualize channel and video metrics, helping users gain actionable insights.

## ⚙️ How It Works

1. User inputs a YouTube channel  
2. API fetches real-time data  
3. Data is processed using analytics logic  
4. Insights are displayed via dashboards
